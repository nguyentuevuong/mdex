# MD Exporter (mdex)

A fast, minimalist, and feature-rich Markdown to Static HTML exporter. Built for documentation sites, personal wikis, and knowledge bases.

## ✨ Features

- **🚀 Static & Fast**: Converts Markdown files to pure HTML/CSS/JS. No database, no backend server required.
- **🎨 Beautiful Themes**:
    - **Modern** (Light/Clean)
    - **Dark** (Easy on eyes)
    - **Midnight** (Deep blue/black)
    - **Zed** (Inspired by Zed Editor - *New!*)
- **🌗 Dynamic Theme Switcher**: Toggle themes instantly via the UI sidebar.
- **🧜 Mermaid.js Support**: Auto-renders `mermaid` code blocks into interactive diagrams.
- **📂 Smart Navigation**:
    - Auto-generates sidebar from folder structure.
    - collapsible folders with state memory.
    - Intelligent sorting (supports dynamic numeric prefixes like `01. Intro` -> `Intro`).
- **📱 Responsive Design**: Mobile-friendly navigation with slide-out menus.
- **🔍 Syntax Highlighting**: Integrated `highlight.js` for all code blocks.
- **📄 Pagination**: Automatic "Previous" and "Next" links in the footer.
- **⚙️ Customizable**: Configurable custom HTML headers and footers via CLI.

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/mdex.git
cd mdex

# Install dependencies
npm install

# Link globally (optional)
npm link
```

## 🛠 Usage

Basic usage:
```bash
mdex -i ./docs -o ./dist
```

### Command Line Options

| Option | Alias | Description | Default |
|--------|-------|-------------|---------|
| `--input` | `-i` | Input directory containing Markdown files | `./docs` |
| `--output` | `-o` | Output directory for generated HTML | `./dist` |
| `--theme` | `-t` | Default theme to apply (`modern`, `dark`, `midnight`, `zed`) | `modern` |
| `--header` | | Custom HTML for the sidebar header | `<h3>Docs</h3>` |
| `--footer` | | Custom HTML for the footer | `Generated by...` |
| `--help` | `-h` | Show help message | |

### Example

Generate documentation with the **Zed** theme and a custom header:

```bash
mdex -i ./my-notes -o ./public -t zed --header "<h3>My Wiki</h3>"
```

## 📝 Markdown Features Support

### 1. Frontmatter
Supports standard YAML frontmatter:
```yaml
---
title: Custom Page Title
description: Description for metadata
date: 2024-01-30
---
```

### 2. Mermaid Diagrams
Just use the `mermaid` language fence:
\`\`\`mermaid
graph TD;
    A-->B;
    A-->C;
    B-->D;
    C-->D;
\`\`\`

### 3. Syntax Highlighting
Supports all common languages via highlight.js:
\`\`\`javascript
console.log("Hello World");
\`\`\`
